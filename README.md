# Soulstrider: Necro-Dominion

A dark gothic action RPG for Android: a hooded reaper against legions of skeletons, specters and skeletal colossi. Play with a controller (Bluetooth or USB) or the touch screen, solo or in local co-op.

**Download:** get the latest `Soulstrider_vX.Y.Z.apk` from [Releases](../../releases/latest). The game checks for new versions on start-up and offers the update on the title screen.

This repository holds the build packages (`projeto.zip` and the `arte_*.zip` art packs). GitHub Actions builds the APK on every push to `main`.
